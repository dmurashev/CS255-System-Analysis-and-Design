# CS 255 System Analysis and Design

This repository contains my work from SNHU CS 255: System Analysis and Design.

The course focuses on system requirements, process modeling, object modeling, UML diagrams, and system design.

## DriverPass Project

The main project in this course is the DriverPass system. The project includes:

- Business requirements
- Gantt chart
- UML use case diagrams
- Process modeling
- Object modeling
- System design documentation

DriverPass was the client for the project. The company wanted a web-based system to help students prepare for driving tests. The system included training packages, online classes, practice tests, and scheduling driving lessons.

## What I Did Well

I think I did well identifying the main requirements and turning them into UML diagrams. The scheduling and practice-test activity diagrams showed the main processes clearly, including package hours, driver and vehicle availability, and scheduling conflicts.

## What I Would Revise

If I revised these projects, I would add more specific details to some parts of the Business Requirements Document, especially the user interface and system limitations. I would also add more detail to the technical requirements in Project Two and include alternative situations in the sequence diagram.

## Understanding User Needs

I used the DriverPass interview to understand what customers and employees needed from the system. For example, customers needed to schedule lessons and take practice tests, while employees needed to manage appointments, accounts, reports, and training packages. It is important to understand user needs because the system should solve the actual problems the users have.

## My Approach to Software Design

I usually start by understanding the problem and identifying the users and requirements. Then I break the system into smaller processes and use diagrams to show how the system should work. In the future, I would continue using requirements, UML diagrams, and feedback from users and team members before development begins.
