# CS 255 System Analysis and Design

This repository contains my work from SNHU CS 255: System Analysis and Design.

The course focuses on system requirements, process modeling, object modeling, UML diagrams, and system design.

## DriverPass Project

The main project in this course is the DriverPass system. The project includes:

- Business requirements
- Gantt chart
- UML use case diagrams
- Process modeling
- Object modeling
- System design documentation
